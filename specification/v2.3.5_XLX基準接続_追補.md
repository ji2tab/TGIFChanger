# TGIFChanger-Py v2.3.5 仕様追補 — XLX 基準接続

v2.3.4 の各仕様書に対する差分をまとめた追補です。ここに書かれていない点は、v2.3.4 の仕様書のとおりです。

## 1. 目的

待機先を XLX リフレクターのモジュールに置き、TGIF は必要なときだけ接続する運用（XLX 基準接続）に対応する。従来の TGIF 直結の動作は変えない。

## 2. 動作モード

| モード | 条件 | 復帰時の動作 |
|---|---|---|
| TGIF 直結 | 下記以外 | TGIF の `RESTORE_TG` へ復帰する（従来どおり） |
| XLX 基準接続 | DMRGateway の `[XLX Network]` が `Enabled=1`、かつ `RESTORE_TG` が `4000` | TGIF を切断する（API に TG4000 を指定）。XLX の待機に戻る |

モードによって変わるのは、ログの文言と `status` の `mode` だけである。ログ監視、復帰タイマー、コールサイン・ウォッチドッグ、API の呼び出し形式（`{TGIF_API}/{DMR_ID}/{SLOT_INDEX}/{RESTORE_TG}`）は共通。

## 3. tgif_daemon.py の変更

### 3.1 追加した関数

| 関数 | 内容 |
|---|---|
| `get_xlx_base()` | `/etc/dmrgateway` の `[XLX Network]` から `Enabled`、`Startup`、`Module`、`TG`、`Slot` を読む |
| `xlx_label(xlx)` | 表示用の名前を返す（例: `XLX950 A`） |
| `_tgif_rewrites()` | TGIF 接続の `TGRewrite` 規則を列挙する |
| `check_xlx_consistency(xlx, watch_tg, restore_tg)` | XLX 基準接続の設定不整合を警告文のリストで返す |
| `App.refresh_tgs()` | 監視TG、復帰TG、XLX の情報、動作モードを再計算する。起動時、`reload`、`SIGHUP` で呼ぶ |
| `App.log_mode()` | 動作モードと警告をログに出す |

### 3.2 `get_dynamic_tgs()` の変更

`WATCH_TG` と `RESTORE_TG` の決定順は次のとおり。

1. `tgifchanger.conf` に両方あれば、その値を使う（従来どおり）。
2. 【追加】`[XLX Network]` が有効で `TG` があれば、不足している側を `WATCH_TG = [XLX Network] の TG`、`RESTORE_TG = 4000` で補う。
3. TGIF 接続の最初の `TGRewrite` から抽出する（従来どおり）。【変更】ただし、宛先が TG4000 の規則（TG の遮断用）は飛ばす。
4. 既定値 `WATCH_TG = 1`、`RESTORE_TG = 4000`（従来どおり）。

### 3.3 設定不整合の警告

`[XLX Network]` が有効なとき、次の場合に `⚠️ [設定]` で始まる警告をログに出す。動作は止めない。

| 条件 | 意味 |
|---|---|
| `WATCH_TG` ≠ `[XLX Network]` の `TG` | 待機TGの通話を待機中として扱えない |
| `RESTORE_TG` ≠ `4000` | TGIF のTGに常時接続し続ける。XLX とブリッジされたTGなら二重配信になる |
| TGIF 接続に「待機TG → TG4000 以外」の `TGRewrite` がある | TGIF 側の音声が待機TGとして RF に出て、XLX 経由の音声と二重になる恐れがある |

### 3.4 `status` の追加項目

| キー | 値 |
|---|---|
| `mode` | `"xlx_base"` または `"tgif_direct"` |
| `xlx` | `[XLX Network]` が有効なら接続先の表示名（例: `"XLX950 A"`）、無効なら `null` |

### 3.5 ログの変更

- 起動時とリロード時: `MODE=XLX基準接続  待機=XLX950 A (TG6)  TGIF は他TG利用後 120s で切断 (TG4000)`、または `MODE=TGIF直結  ホームTG<番号>`。
- 復帰時（XLX 基準接続）: `🔄 TGIF を切断中 (TG4000)... → XLX950 A の待機へ復帰`。

## 4. tg_change.py の変更

バージョン表記と、ヘルプへの XLX 基準接続の設定例の追加のみ。動作の変更はない。

## 5. install.sh の変更

- `[XLX Network]` が `Enabled=1` で `TG` があれば、推奨値を `WATCH_TG = [XLX Network] の TG`、`RESTORE_TG = 4000` にする。
- `TGRewrite` の自動抽出で、宛先が TG4000 の規則を飛ばす。
- 生成する設定ファイルのテンプレートに、XLX 基準接続の説明を追加。

## 6. tgifchanger.conf の変更

- `WATCH_TG` / `RESTORE_TG` に、TGIF 直結と XLX 基準接続それぞれの設定方法の説明を追加。
- サンプルに `CALLSIGN_TIMEOUT` の行を追加（v2.3.4 で追加された項目が、リポジトリのサンプルに入っていなかった）。
- サンプルの値（`WATCH_TG="1"`、`RESTORE_TG="168"`）は変更していない。

## 7. 互換性

- `[XLX Network]` が無効の環境では、動作は v2.3.4 と同じ。
- `tgifchanger.conf` に `WATCH_TG` と `RESTORE_TG` の両方が書かれている環境では、値の決定は v2.3.4 と同じ。
- 既存の `tgifchanger.conf` はそのまま使える。
