## 1. 概要

TGIFChanger-Py の設定ファイルです。**Bash の KEY=VALUE 形式**で記述され、以下の3つのコンポーネントから共通して読み込まれます。

| コンポーネント | 用途 |
|--------------|------|
| `install.sh` | インストール時の対話プロンプトのデフォルト値として参照 |
| `tgif_daemon.py` | 起動時および `SIGHUP` / `reload` コマンド受信時に読み込み |
| `tg_change.py` | 設定確認・変更・TGIF API 呼び出し時に参照 |

### 設定の反映ルール

| 変更方法 | 反映タイミング |
|---------|--------------|
| `tg_change -w/-r/-t/-k` コマンド | デーモンへ即時反映（`reload` コマンド自動送信） |
| `nano` 等で直接編集 | `sudo systemctl restart tgifchanger-py` が必要 |

---

## 2. ファイルフォーマット

```bash
KEY="value"    # ダブルクォートで囲む（推奨）
KEY='value'    # シングルクォートも可
KEY=value      # クォートなしも読み込み可能
# コメント行  → 行頭に # を付ける
```

- コメント行（`#` 始まり）・空行は無視されます
- `=` を含まない行は無視されます
- 値のクォート（シングル・ダブル）は読み込み時に自動除去されます

## 3. パラメータ仕様

### 3.1 ログ監視

#### `LOG_DIR`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `/var/log/pi-star` |
| 型 | 文字列（ディレクトリパス） |
| 説明 | `MMDVM-*.log` を探索するディレクトリ。Pi-Star / WPSD 標準のログ出力先を指定します。 |

---

### 3.2 DMR スロット制御

#### `WATCH_SLOT`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `2` |
| 型 | 整数（`1` または `2`） |
| 説明 | 監視対象の DMR タイムスロット番号。ログ行中の `Slot N,` マーカーと照合します。 |

#### `RESTORE_SLOT`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `2` |
| 型 | 整数（`1` または `2`） |
| 説明 | TGIF API への復帰リクエスト送信時に使用するタイムスロット番号。API エンドポイントの `SLOT_INDEX`（スロット番号 - 1）に変換されます。 |

---

### 3.3 トークグループ制御

#### `WATCH_TG`

| 項目 | 内容 |
|------|------|
| サンプル値 | `1` |
| 型 | 整数（DMR トークグループ番号） |
| 説明 | 受信を監視するトークグループ番号。このTGへの `voice header` 検出時に GPIO を HIGH にセットし、復帰タイマーをキャンセルします。空の場合は `tgif_daemon.py` が DMRGateway / MMDVMHost の TGRewrite から自動抽出します。 |

#### `RESTORE_TG`

| 項目 | 内容 |
|------|------|
| サンプル値 | `168` |
| 型 | 整数（DMR トークグループ番号） |
| 説明 | `RESTORE_DELAY` 秒後に自動復帰する先のトークグループ番号。`4000` を指定すると TGIF から切断（Disconnect）します。空の場合は TGRewrite から自動抽出し、それも失敗した場合は `4000` をフォールバックとして使用します。 |

#### `RESTORE_DELAY`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `120` |
| 型 | 整数（秒） |
| 説明 | `WATCH_TG` / `RESTORE_TG` 以外のTGへの通話終了を検知してから `RESTORE_TG` へ自動復帰するまでの待機時間。`tg_change -t <秒>` で変更できます。 |

#### `CALLSIGN_TIMEOUT`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `300` |
| 型 | 整数（秒） |
| 説明 | コールサイン・ウォッチドッグ（真の利用者監視）の監視時間。他TGへ **RF（自局側）でキーアップした最後の局** を「真の利用者」として追跡し、その局の RF を本秒数だけ確認できなければ、ネット側（リモート）の通話が続いていても `RESTORE_TG` へ強制復帰します。network 受信（リモート通話）はカウント対象外で、別の局が RF キーアップすると追跡対象を切り替えます。`0` を指定すると本機能は無効になり、従来どおり `RESTORE_DELAY` のみで動作します。`tg_change -k <秒>` で変更できます（`RESTORE_DELAY` より短い値を指定すると警告が表示されます）。 |

---

### 3.4 GPIO 制御

#### `GPIO_PIN`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `17` |
| 型 | 整数（BCM ピン番号） |
| 説明 | GPIO 出力ピン番号（BCM 番号体系）。`WATCH_TG` への受信中は HIGH、それ以外は LOW を出力します。OpenCCVoice / Arduino との連携に使用します。 |

#### `GPIO_BACKEND`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `auto` |
| 型 | 文字列 |
| 説明 | GPIO 制御に使用するバックエンドを指定します。 |

選択値:

| 値 | 動作 |
|----|------|
| `auto` | `pinctrl` → `raspi-gpio` → `sysfs` の順で利用可能なバックエンドを自動選択。Pi-Star (Buster) on Pi Zero 2W で動作実績あり |
| `libgpiod` | libgpiod v1/v2 を使用。Bookworm 環境で推奨。`gpiodetect` で BCM チップを自動判定 |
| `pinctrl` | `pinctrl` コマンドを強制使用 |
| `raspi-gpio` | `raspi-gpio` コマンドを強制使用 |
| `sysfs` | `/sys/class/gpio` を経由する sysfs インターフェイスを強制使用 |
| `null` | GPIO を無効化（テスト・デバッグ用） |

#### `GPIO_CHIP`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `auto` |
| 型 | 文字列 |
| 有効条件 | `GPIO_BACKEND="libgpiod"` の場合のみ有効 |
| 説明 | libgpiod が使用する gpiochip を指定します。 |

選択値:

| 値 | 動作 |
|----|------|
| `auto` | `gpiodetect` で BCM チップ（`pinctrl-bcm2xxx`）を自動判定。通常は `gpiochip0` |
| `0` | チップ番号を直接指定（`gpiochip0` に変換） |
| `gpiochip0` | チップ名を直接指定 |

---

### 3.5 TGIF API

#### `TGIF_API`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `http://tgif.network:5040/api/sessions/update` |
| 型 | URL 文字列 |
| 説明 | トークグループ変更に使用する TGIF セッション更新 API のベース URL。実際のリクエストは `{TGIF_API}/{DMR_ID}/{SLOT_INDEX}/{TG番号}` の形式で GET 送信されます。 |

#### `TGIF_API_TIMEOUT`

| 項目 | 内容 |
|------|------|
| デフォルト値 | `10` |
| 型 | 整数（秒） |
| 説明 | TGIF API への HTTP リクエストのタイムアウト時間。この秒数を超えると通信エラーとしてログに記録されます。 |

## 4. パラメータ一覧（早見表）

| パラメータ | サンプル値 | 変更コマンド | 説明 |
|-----------|-----------|------------|------|
| `LOG_DIR` | `/var/log/pi-star` | 手動編集のみ | MMDVM ログディレクトリ |

| `RESTORE_SLOT` | `2` | 手動編集のみ | 復帰タイムスロット |

| `GPIO_PIN` | `17` | 手動編集のみ | GPIO 出力ピン番号（BCM） |
| `GPIO_BACKEND` | `auto` | 手動編集のみ | GPIO バックエンド |
| `GPIO_CHIP` | `auto` | 手動編集のみ | gpiochip 番号（libgpiod 用） |
| `TGIF_API` | `http://tgif.network:5040/...` | 手動編集のみ | TGIF API エンドポイント |
| `TGIF_API_TIMEOUT` | `10` | 手動編集のみ | API タイムアウト（秒） |

## 5. 設定ファイルの管理

### 場所

```
/etc/tgifchanger.conf
```

### アップグレード時の扱い

`install.sh` v2.3.1 以降では、既存の設定ファイルが存在する場合は**上書きせず保持**します。新バージョンの設定テンプレートは `/etc/tgifchanger.conf.new` として別途保存されます。差分を確認して必要なパラメータを手動でマージしてください。

### 書き込み時の安全性

`tg_change` コマンド（v2.3.2 以降）による書き込みは、`fcntl.flock` による排他ロックと `os.replace` によるアトミック書き込みで保護されています。複数プロセスからの同時書き込みによるファイル破損は発生しません。
